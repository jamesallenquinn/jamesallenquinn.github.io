Install

iPhone: open this page in Safari, tap Share, then Add to Home Screen. If the mic does nothing from the home screen icon, run it inside Safari instead; older iOS versions only allow speech recognition there.

PC: use Chrome or Edge. Click the install icon in the address bar to get a standalone window. Firefox does not support speech recognition.
