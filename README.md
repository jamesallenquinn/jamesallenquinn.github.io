# jamesallenquinn.github.io

Small iPhone web apps. Open one in Safari, then Share → **Add to Home Screen** to install it.

| App | Link | What it does |
| --- | --- | --- |
| Bills | [/bills/](https://jamesallenquinn.github.io/bills/) | Track bills, subscriptions, and recurring payments. Color-coded categories, upcoming view, mark as paid, monthly totals, a supplies budget (diapers, formula, paper goods) estimated from usage and price, and import from a Google Calendar export (.ics). Works offline. |
| Twin Feeding Log | [/twin-feeding-log-iphone.html](https://jamesallenquinn.github.io/twin-feeding-log-iphone.html) | Tap a button when Julian or Rowan eats. |

All data stays on the phone in local storage. The Bills app has a backup/restore option under **More**.
